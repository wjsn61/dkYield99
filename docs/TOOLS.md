## 1️⃣ 폴더 열기 - 파일 하나가 아니라 폴더를

**파일 → 폴더 열기 →** 게임 폴더(예: `C:\dk\dkYield99`)를 통째로 엽니다.

⚠️ 파일 하나만 열면 `python w12_basic.py` 가 "파일을 찾을 수 없다"고 합니다.
**폴더를 열어야** 터미널이 그 폴더에서 시작합니다.

---

## 2️⃣ 터미널 열기

**`Ctrl` + `` ` ``** (숫자 1 왼쪽의 백틱 키) - 아래쪽에 검은 창이 열립니다.

```
PS C:\dk\dkYield99>  cd lab
PS C:\dk\dkYield99\lab>  python w12_basic.py
```

이 두 줄이 이 수업에서 쓰는 명령의 전부입니다.

| 명령 | 뜻 |
|---|---|
| `cd lab` | 실습 폴더로 들어간다 |
| `cd ..` | 한 단계 나온다 |
| `python 파일.py` | 그 파일을 처음부터 끝까지 돌린다 |
| `↑` 키 | 방금 친 명령 다시 꺼내기 |

## 3️⃣ 파이썬 고르기 (한 번만)

`Ctrl+Shift+P` → **`Python: Select Interpreter`** → 목록에서
게임 폴더 안의 **`.\python\python.exe`** 를 고릅니다.

> 내 PC에 다른 파이썬이 깔려 있어도 상관없습니다.
> 게임 전용 파이썬을 고르면 **선생님 PC와 똑같은 환경**이 됩니다.

## 4️⃣ 셀 단위로 돌리기 - `# %%`

11주부터는 값을 이리저리 바꿔 보게 됩니다.
그때마다 파일 전체를 다시 돌리면 답답합니다. **`# %%`** 를 쓰세요.

```python
# %%
값들 = load_column(CSV, "수율")
len(값들)                    # Shift+Enter → 오른쪽 창에 바로 결과

# %%
my_mean(값들)                # 이 블록만 다시 실행

# %%
import matplotlib.pyplot as plt
plt.hist(값들)               # 그림도 옆 창에 바로
```

**`# %%`** 를 한 줄 써 두면 그 아래가 한 덩어리(셀)가 되고,
그 안에서 **`Shift`+`Enter`** 를 누르면 **그 덩어리만** 실행됩니다.
결과와 그림은 오른쪽 **대화형 창(Interactive Window)** 에 쌓입니다.

> 처음 한 번은 프로젝트 폴더의 **`install_stats.bat`** 을 실행해야 합니다.
> (`ipykernel` 이 있어야 셀 실행이 됩니다. 게임에는 필요 없습니다)

**그래도 파일은 평범한 `.py` 입니다.** `# %%` 는 그냥 주석이라
`python 파일.py` 로 처음부터 끝까지 돌리면 똑같이 돕니다.

## ❓ 주피터 노트북(.ipynb)은 왜 안 쓰나요

자주 나오는 질문입니다. **셀 실행은 그대로 쓰되, 파일은 `.py` 로 둡니다.**

VS Code의 Jupyter 확장은 두 가지를 다 해 줍니다.

| | 파일 | 이 수업에서 |
|---|---|---|
| **대화형 창** (`# %%`) | 평범한 `.py` | ✅ **이걸 씁니다** |
| 노트북 편집기 | `.ipynb` | ❌ 쓰지 않습니다 |

**엔진은 똑같습니다** - 둘 다 `ipykernel` 위에서 돕니다.
셀 실행도, 인라인 그림도, 변수 탐색기도 똑같이 됩니다.
다른 건 **디스크에 남는 파일** 하나뿐이고, 그 하나가 중요합니다.

### 이유 ① 노트북은 실행 순서를 지키지 않아도 돌아갑니다

셀 7을 먼저 돌리고 셀 3을 나중에 돌려도 노트북은 잘 돌아갑니다.
그런데 **그 노트북을 위에서부터 다시 돌리면 에러가 납니다.**

이건 초보자가 가장 많이 겪는 사고이면서, 동시에

> **재현 불가 제출물(시드·CSV 미첨부)은 해당 과제 최대 70%**

라고 선언한 이 과목의 평가 기준과 **정면으로 부딪히는 상태**입니다.
`.py` 는 위에서 아래로 한 번만 돕니다. 순서가 어긋날 방법이 없습니다.

### 이유 ② 채점자가 재현 여부를 알 수 없습니다

`.ipynb` 는 **출력이 파일 안에 박혀 있는 JSON** 입니다.
화면에 보이는 그 숫자가 지금 코드로 나온 것인지, 세 번 전 코드로 나온 것인지
파일만 봐서는 알 수 없습니다.

`.py` 는 다릅니다 - 돌려 보면 압니다.

### 이유 ③ 제출물이 단순해집니다

> `.py` (내 코드) + `.csv` (내 데이터) + `.png` (내 그림)

세 개면 끝이고, 조교가 그대로 돌려서 같은 결과가 나오는지 확인할 수 있습니다.

### 그럼 노트북은 나쁜 도구인가요

아닙니다. **혼자 탐색할 때는 아주 좋은 도구**이고, 현업에서도 많이 씁니다.
다만 이 과목이 가르치려는 것은 *탐색*이 아니라
**남이 검증할 수 있는 결과물**입니다. 그래서 `.py` 입니다.

졸업 후에 노트북을 쓰게 되더라도, **"이 노트북 위에서부터 다시 돌아가나?"**
를 스스로 묻는 습관은 여기서 배운 것 그대로입니다.

## 🤖 AI를 쓸 때

**써도 됩니다. 다만 규칙이 하나 있습니다.**

> AI가 준 코드를 그대로 내면 안 됩니다.
> **돌려 보고, 내가 만든 함수의 답과 같은지 확인**한 뒤에 쓰세요.

매주 과제에 이 칸이 있습니다.

| 어디서 | 값 |
|---|---|
| ① 내가 짠 코드 | `python w12_basic.py` |
| ② 게임 화면 | 「📊 통계 지표 보기」 |
| ③ AI | "이 숫자들의 표준편차를 구해 줘" |

**셋이 맞아떨어질 때** 비로소 그 숫자를 믿을 수 있습니다.
다르면 어느 쪽이 틀렸는지 찾는 것이 그 주의 진짜 과제입니다.

## ❓ 자주 막히는 곳

| 이런 일이 생기면 | 이렇게 하세요 |
|---|---|
| `python` 을 못 찾음 | `Ctrl+Shift+P` → `Python: Select Interpreter` → 폴더 안 `python\python.exe` |
| `파일을 찾을 수 없습니다` | 폴더가 아니라 파일 하나만 열었습니다. **파일 → 폴더 열기** 로 다시 |
| `cd lab` 이 안 됨 | 이미 `lab` 안입니다. `cd ..` 로 나갔다가 다시 |
| Shift+Enter 가 안 먹음 | Jupyter 확장(`ms-toolsai.jupyter`) 설치 + `install_stats.bat` 실행 |
| 터미널이 안 보임 | `Ctrl` + `` ` `` (백틱). 또는 **보기 → 터미널** |
| 한글이 깨져 보임 | CSV는 `utf-8-sig` 로 저장돼 있습니다. 엑셀에서 그냥 더블클릭하세요 |
| 그림 창이 안 뜸 | `install_stats.bat` 을 먼저 실행하세요 |
