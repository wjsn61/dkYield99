## 2️⃣ 이 파일에서 제일 중요한 지표 — 순도

```python
{
    "키": "순도",                    # 진짜 순도 (우리는 이걸 볼 수 없습니다)
    "관측컬럼": "순도_분석",           # 분석기가 알려주는 값 (이것만 볼 수 있습니다)
    "측정오차": {
        "분포": "정규",
        "표준편차": 0.30,            # 온라인 GC 반복성 ±0.3%p
    },
    "개선설비": {
        "아이디": "online_analyzer",
        "표준편차": 0.15,            # 분석기를 달면 오차가 절반으로
    },
    "관리도": {"종류": "X-bar R", "부분군": 5, "규격하한": 98.0},
}
```

### 여기 숨은 질문

순도가 98.4%에서 98.1%로 떨어졌습니다. **공정이 나빠진 걸까요, 분석기가 튄 걸까요?**

측정오차 표준편차가 0.30이면, 0.3%p 차이는 **1σ 안쪽**입니다. 아무 일도 안 일어났을 때도
흔히 나오는 차이입니다. 여기서 설비를 세우면 헛수고이고, 진짜 이상을 놓치면 반품입니다.

이걸 구분하는 방법이 **관리도**(13주)이고, 측정 자체를 믿을 수 있는지 재는 것이
**측정시스템분석(MSA)** 입니다.

> **온라인 분석기를 설치하면 순도가 오르는 게 아닙니다.**
> 순도를 **더 정확히 알게** 되는 것입니다.
> 이 차이를 아는 것이 품질 엔지니어의 시작입니다.

## 3️⃣ 수율은 왜 파생값인가

```
수율 = 전환율 × 선택도 × 분리회수율 ÷ 10000
```

세 값을 각각 재는데, 셋 다 흔들립니다.

| 요소 | 표준편차 | 왜 |
|---|---|---|
| 전환율 | 0.8 %p | 원료 조성·촉매 상태가 매 배치 다름 |
| 선택도 | 0.5 %p | 부반응 속도 변동 |
| 분리회수율 | 0.4 %p | 증류탑 운전 변동 |

**그러면 수율의 표준편차는 얼마일까요?**

곱셈으로 이어진 값이라 그냥 더하면 안 됩니다. 상대표준편차의 제곱합으로 계산합니다.
14주에 이론값을 손으로 구하고, 실제 데이터의 표준편차와 맞춰 봅니다. **맞으면 짜릿합니다.**

그리고 더 중요한 질문: **셋 중 어느 것의 산포를 줄여야 수율이 안정될까요?**
답은 이 표 안에 있습니다. 이것이 현업의 변동 기여도 분석입니다.

## 4️⃣ 잡음 크기를 바꿔 보기

```python
"측정오차": {"분포": "정규", "표준편차": 0.30},   # ← 0.05 로 바꿔 보세요
```

- 줄이면 → 관리한계가 좁아지고, 작은 이상도 잡아냅니다 (= 비싼 계기를 산 것)
- 늘리면 → 웬만한 변화는 "판단 불가"가 됩니다

**측정을 잘하는 것이 곧 관리를 잘하는 것**임을 숫자로 확인하게 됩니다.

---

## ⚠️ 교란변수를 조심하세요

`"인과": False` 인 지표가 6개 있습니다.

> 촉매활성 · 시장수요 · 압력 · 체류시간 · **환류비** · 유량

`증류 환류비 증가` 카드는 **환류비와 순도를 동시에** 올립니다.
그래서 데이터를 보면 환류비가 높은 판일수록 순도도 높아 보입니다.

하지만 환류비 값 자체는 **어떤 계산에도 쓰이지 않습니다.**
환류비만 바꿔 봐도 순도는 꿈쩍하지 않습니다. 원인이 아니니까요.

14주에 이걸 직접 발견하게 됩니다.
**함께 움직인다고 원인인 것은 아닙니다.** 이 함정에 빠지지 않는 것이
데이터로 일하는 엔지니어의 기본기입니다.

| `표준편차가 0 입니다` | 변동이 없으면 관리도·공정능력지수를 배울 수 없습니다 |
| `잡음이 너무 큽니다` | 카드 효과가 잡음에 묻힙니다. 범위의 20% 아래로 |
| `X-bar R 관리도는 ... '부분군' 크기를` | `{"종류": "X-bar R", "부분군": 5}` 처럼 몇 개씩 뽑는지 적으세요 |
| `개수를 세는 자료라 c관리도가 맞습니다` | **재는** 값에는 `X-MR`, **세는** 값에는 `c` |

## 🎲 시드(seed)가 뭔가요

같은 시드를 넣으면 **언제 다시 돌려도 똑같은 공장**이 나옵니다.

14주 실험계획법(DOE)이 여기에 기댑니다.

> 온도 高/低 × 환류비 高/低 — 네 가지 조건을 **같은 시드로** 돌립니다.
> 시드가 같으니 조업 변동도 똑같습니다.
> 결과의 차이는 **오직 온도와 환류비 때문**입니다.

이렇게 해야 주효과와 교호작용을 분리할 수 있습니다.
과제를 낼 때는 반드시 **시드를 함께 적어 주세요.**
다시 확인할 수 없는 결과는 데이터가 아닙니다.
