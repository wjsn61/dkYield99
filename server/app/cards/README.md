## 1️⃣ 카드 바꾸기 (제일 쉬움)

`cards_data.py` 를 열고 숫자를 바꾸세요.

```python
{
    "아이디": "reactor_temp_up",
    "이름": "반응기 온도 상승",
    "분류": "운전",
    "비용": 0,
    "즉시효과": {"전환율": +5, "선택도": -3, "에너지비": +3, "반응기온도": +10},
    "부작용": {"안전지수": -5, "순도": -2},   # ← -5를 -2로 바꾸면 덜 위험해집니다
},
```

- `+` 면 늘고, `-` 면 줄어듭니다.
- 줄 끝의 **쉼표 `,` 는 지우지 마세요.**
- **수율은 직접 못 바꿉니다** — `수율 = 전환율 × 선택도 × 분리회수율` 로 자동 계산됩니다.
  수율을 올리려면 전환율·선택도·분리회수율을 올리세요.

## 2️⃣ 카드 추가하기

분류는 **운전 / 설비 / 연구 / 안전환경 / 시장** 중 하나입니다.

**운전·설비 카드** (즉시효과 필요):
```python
{
    "아이디": "my_card",
    "이름": "촉매 추가 투입",
    "분류": "운전",
    "비용": 3,
    "즉시효과": {"전환율": +4, "촉매비": +2},
},
```

**연구(R&D) 카드** (연구기간 + 성공효과 필요):
```python
{
    "아이디": "my_research",
    "이름": "신촉매 연구",
    "분류": "연구",
    "비용": 15,
    "연구기간": 4,                       # 4턴 뒤 성공효과 반영
    "성공효과": {"선택도": +8, "전환율": +3},
},
```

## 🧩 카드 한 장에 들어가는 항목

| 항목 | 필수? | 뜻 |
|---|---|---|
| `아이디` | ✅ | 영어 식별자 (겹치면 안 됨) |
| `이름` | ✅ | 화면에 보일 한글 이름 |
| `분류` | ✅ | 운전 / 설비 / 연구 / 안전환경 / 시장 |
| `비용` | ✅ | 시행 비용(억) |
| `즉시효과` | 운전·설비 ✅ | 바로 적용되는 변화 |
| `연구기간`·`성공효과` | 연구 ✅ | N턴 뒤 반영되는 효과 |
| `부작용` | ⬜ | 나쁜 영향 |
| `장기효과` | ⬜ | 설비가 매 턴 주는 효과 |
| `유지비`·`일회성` | ⬜ | 설비 전용 (매 턴 비용 / 한 번만 설치) |

**쓸 수 있는 지표 이름**:
> 예산 · 월이익 · 생산량 · 순도 · 안전지수 · 환경지수 ·
> 전환율 · 선택도 · 분리회수율 · 촉매활성 ·
> 에너지비 · 원료비 · 촉매비 · 환경처리비 ·
> 설비노후도 · 기술력 · 제품단가 · 시장수요 ·
> 반응기온도 · 압력 · 체류시간 · 환류비 · 유량
