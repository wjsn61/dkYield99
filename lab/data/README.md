# 📊 data 폴더

여기에 **CSV 파일**이 모입니다. 분석의 재료입니다.

## 어떻게 채우나요

### ① 게임에서 내려받기

게임 화면 아래 **「📊 통계 지표 보기」** → 오른쪽 위 **「📥 엑셀용 CSV」**

- 지금 하고 있는 판의 **턴별 기록**이 저장됩니다.
- 브라우저 다운로드 폴더와 **이 폴더에 동시에** 저장됩니다.

**「💾 저장 · 불러오기」** 에서는 여러 판을 한 파일로 합칠 수 있습니다.

| 버튼 | 모양 |
|---|---|
| 📥 합본 CSV (턴별) | 한 줄에 한 턴 — 여러 판이 이어 붙습니다 |
| 📥 판별 요약 CSV | **한 줄에 한 판** — 판이 20개면 표본 20개 |
| 📥 긴 형식 CSV | 한 줄에 지표 하나 — 피벗테이블 연습용 |

### ② 자동으로 여러 판 돌리기

```
python run_batch.py --strategy 품질형 --n 20
```

## 컬럼 이름이 파일마다 조금 다릅니다

| 파일 | 수율 컬럼 이름 | 한 줄이 뜻하는 것 |
|---|---|---|
| 게임에서 내려받은 CSV | `수율` | 한 달 |
| 판별 요약 CSV | `최종_수율` | 한 판 |
| `run_batch.py --level game` | `최종_수율` | 한 판 |
| `run_batch.py --level turn` | `수율` | 한 달 |

`w12_basic.py` 의 `column(rows, "수율")` 는 두 이름을 모두 찾아 주므로
그냥 `"수율"` 이라고 쓰면 됩니다.

## 한글이 깨지지 않나요

엑셀에서 그냥 더블클릭해서 열면 됩니다.
컬럼 이름이 깨지지 않도록 **BOM**을 넣어 저장하고 있습니다.

## 이 파일들을 지워도 되나요

네. 언제든 다시 만들 수 있습니다.
다만 **과제로 제출한 결과의 CSV는 지우지 마세요.**
재현할 수 없는 결과는 증거가 아닙니다.
