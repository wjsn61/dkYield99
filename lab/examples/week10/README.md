# 10주 - 데이터를 남긴다 - 저장 · 라벨 · CSV

> **학습 목표** - 판을 이름 붙여 저장하고 성공/실패 라벨을 달아, 나중에 비교할 수 있는 데이터로 만든다.

## 이 폴더의 예제

| 파일 | 무엇을 | 하는 일 |
|---|---|---|
| `01_write_csv.py` | csv.DictWriter - CSV 로 남기기 | 프로그램이 만든 값을 파일로 저장합니다. csv 모듈로 쓰고, 왜 utf-8-sig 로 저장해야 하는지 확인합니다. |
| `02_read_csv.py` | csv.DictReader · float( ) - 다시 읽기 | 저장한 CSV 를 다시 읽습니다. 읽으면 모두 '글자' 라서 숫자로 바꿔야 계산된다는 것을 확인합니다. |
| `03_where_is_data.py` | os.path - 내 데이터는 어디 있나 | lab/data 폴더에 무엇이 쌓여 있는지 확인하고, 아직 없다면 어떻게 만드는지 안내합니다. |

**번호 순서대로 여세요.** 앞 파일을 알아야 뒤 파일이 읽힙니다.

각 파일 맨 위에 *이 파일이 하는 일* 이 적혀 있고, 처음 나오는 문법은 그 줄 옆에 주석으로 설명해 두었습니다.

## 이번 주 내용

**Python - 파일과 경로**

프로그램이 만든 값은 끄면 사라집니다. 파일로 써야 남습니다. 저장하면 같은 이름의 CSV가 lab\data\ 에 함께 생깁니다.

**전공 - 배치기록과 추적성**

기록되지 않은 배치는 없던 배치입니다. 무엇을·언제·어떤 기준으로 측정했는지가 곧 그 공정의 신뢰도입니다.

**실습 - 판을 이름 붙여 저장**

판마다 이름·성공/실패 라벨·메모를 남깁니다. 라벨 기준은 여러분이 정하고, 그 기준을 글로 적어야 합니다.

**데이터·통계 - 표본 하나 = 판 하나**

판을 20번 저장하면 표본이 20개입니다. 표본이 적으면 어떤 통계도 소용없습니다. 모으는 일이 먼저입니다.
