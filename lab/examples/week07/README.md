## 이번 주 내용

**Python - 모듈과 호출 흐름**

프로그램은 함수가 함수를 부르며 굴러갑니다. import 로 다른 파일을 가져오고, 한 함수가 끝나면 어디로 돌아가는지를 따라
읽는 것이 코드 읽기의 전부입니다.

**전공 - 공정 계통과 피드백 루프**

환류비를 올리면 순도가 오르지만 재비열이 늘고, 에너지비가 늘면 이익이 줄어 설비 투자가 밀립니다. 이렇게 돌아오는 피드백 루프를
못 보면 조건 변경은 늘 예상 밖으로 갑니다.

**실습 - end_turn() 한 줄씩 따라가기**

end_turn() → calculate_yield() → calculate_revenue() → 안전·환경 점검. 생산 실행
버튼 하나가 부르는 함수들을 순서대로 짚습니다.
