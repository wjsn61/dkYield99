# 9주 - 같은 선택, 다른 결과 - 시드와 반복

> **학습 목표** - 똑같이 해도 결과가 매번 다르다는 것을 확인하고, 시드로 그 차이를 다시 만들어 낸다.

## 이 폴더의 예제

| 파일 | 무엇을 | 하는 일 |
|---|---|---|
| `01_same_seed.py` | seed - 같은 씨앗이면 같은 세상 | seed 를 주면 몇 번을 돌려도 같은 결과가 나온다는 것을 확인합니다. 재현성이 이 과목 평가의 기준이라 가장 중요한 개념입니다. |
| `02_five_seeds.py` | zip( ) - 같은 전략, 시드만 바꿔 5번 | 똑같이 해도 결과가 매번 다르다는 것을 표와 막대로 눈에 보이게 만듭니다. |
| `03_spread.py` | max( ) - min( ) - 얼마나 흩어졌나 | 열 번 돌린 결과의 최대·최소 차이를 봅니다. 이 '흩어짐' 이 후반부의 주제입니다. |

**번호 순서대로 여세요.** 앞 파일을 알아야 뒤 파일이 읽힙니다.

각 파일 맨 위에 *이 파일이 하는 일* 이 적혀 있고, 처음 나오는 문법은 그 줄 옆에 주석으로 설명해 두었습니다.

## 이번 주 내용

**Python - 모듈 불러오기와 반복 호출**

다른 파일의 기능을 import 로 가져다 씁니다. 같은 함수를 여러 번 부르고 결과를 리스트에 모으면, 한 번으로는 안 보이던
것이 보입니다.

**전공 - 공정 변동과 재현성**

같은 레시피도 원료 로트·주변온도·계측기에 따라 결과가 달라집니다. 한 배치의 성공으로 조건을 확정하는 것이 현장에서 가장 흔한
오류입니다.

**실습 - 같은 전략, 시드 5개**

run_batch.py 로 같은 운전 전략을 시드만 바꿔 5번 돌립니다. 최종 수율과 순도가 매번 다릅니다.

**데이터·통계 - 한 번은 아무것도 증명하지 않는다**

같은 조건인데 결과가 흩어집니다. 이 흩어짐이 이번 학기 후반부의 주제입니다. 아직 계산은 하지 않고, 눈으로만 봅니다.
