# 11주 - 엑셀로 읽는 숫자

> **학습 목표** - 내가 만든 CSV를 엑셀로 열어 평균·표준편차를 구하고, 라벨별로 집계한다.

## 이 폴더의 예제

| 파일 | 무엇을 | 하는 일 |
|---|---|---|
| `01_csv_is_text.py` | pathlib.Path · .glob( ) - CSV 는 그냥 글자 | CSV 파일을 열어 글자 그대로 찍어 봅니다. 엑셀도 파이썬도 이 글자를 읽는 도구일 뿐이라는 것을 확인합니다. |
| `02_excel_vs_python.py` | 엑셀 함수 ↔ 파이썬 - 같은 계산 두 표기 | 엑셀에서 쓰는 함수와 파이썬에서 같은 일을 하는 코드를 나란히 놓고 비교합니다. |
| `03_excel_checklist.py` | STDEV.S vs STDEV.P - 엑셀 과제 | 엑셀에서 할 일의 순서를 확인하고, 구한 표준편차 값을 다음 주 대조용으로 적어 둡니다. |

각 파일 맨 위에 *이 파일이 하는 일* 이 적혀 있고, 처음 나오는 문법은 그 줄 옆에 주석으로 설명해 두었습니다.

## 이번 주 내용

**Python - CSV는 그냥 글자입니다 · VS Code 셀 실행**

CSV를 메모장으로 열어 보세요. 쉼표로 나뉜 글자일 뿐입니다. 엑셀도 파이썬도 이 글자를 읽는 도구입니다.
이번 주부터 # %% 를 씁니다 - 그 줄 아래가 한 덩어리가 되고 Shift+Enter 로 그 덩어리만 실행됩니다. 파일은
그대로 평범한 .py 입니다.

**전공 - 운전일지와 집계**

현장 일지도 결국 표 하나입니다. 평균만 보면 놓치는 것 - 흩어짐과 이상치를 함께 봅니다.

**실습 - 판별 요약 CSV**

한 줄이 한 판인 CSV를 엑셀로 열어, 라벨별 최종 수율·순도·안전지수를 집계합니다.

**데이터·통계 - 직접 만드는 다섯 값**

AVERAGE(평균) · MEDIAN(중앙값) · STDEV.S(표준편차) · MAX · MIN. 이 다섯은 학생이 직접
구합니다. 피벗으로 라벨별 평균도 냅니다.
