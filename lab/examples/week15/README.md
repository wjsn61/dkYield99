# 15주 - 보고서와 발표 - 내 데이터로 말하기

> **학습 목표** - 내가 만든 데이터로 결론을 말하고, 그 결론이 틀릴 수 있는 지점까지 함께 발표한다.

## 이 폴더의 예제

| 파일 | 무엇을 | 하는 일 |
|---|---|---|
| `01_dataset_spec.py` | 내 데이터는 어떻게 만들어졌나 | 발표 첫 장에 들어갈 내용입니다. 시드·판 수·라벨 기준을 확인하고 한 문단으로 적습니다. |
| `02_my_numbers.py` | 발표 숫자는 내 코드가 낸 것으로 | 최종 데이터에 내 함수를 다시 돌려 숫자를 확정하고, 게임 화면 값과 대조합니다. |
| `03_checklist.py` | all( ) - 필수 3요소 자가 점검 | 발표 필수 3요소가 준비됐는지 스스로 점검합니다. 하나라도 없으면 발표 상한 70% 입니다. |

**번호 순서대로 여세요.** 앞 파일을 알아야 뒤 파일이 읽힙니다.

각 파일 맨 위에 *이 파일이 하는 일* 이 적혀 있고, 처음 나오는 문법은 그 줄 옆에 주석으로 설명해 두었습니다.

## 이번 주 내용

**Python - 내 코드로 다시 확인**

12주에 채운 w12_basic.py 를 최종 데이터에 그대로 돌립니다. 발표에 쓰는 숫자는 내 코드가 낸 숫자여야 합니다.

**전공 - 근거를 밝히는 엔지니어링**

기술보고서의 신뢰는 결론이 아니라 근거를 어디까지 밝혔는가에서 옵니다. 측정 방법·배치 수·한계를 적지 않은 보고서는 채택되지
않습니다.

**실습 - 최종 평가와 검증**

최종 수율·순도·안전지수로 결과를 보되, 등급보다 그 등급을 어떻게 얻었는지를 검증합니다.

**데이터·통계 - 세 문장으로 끝내기**

수치(내가 본 값과 단위) · 판단(그래서 무엇이라 결론짓는가) · 한계(이 결론이 틀릴 수 있는 이유). 한계가 비면
감점입니다.

## 실습 단계

1. 최종 데이터셋 확정 - 시드·판 수·라벨 기준을 문서에 적기
2. w12_basic.py 로 최종 수치를 내 코드로 다시 계산
3. 분포 그림 1장 생성 (w12_chart.py)
4. 발표(7분) - 수치·판단·한계 순서로
5. 동료 발표에 질문하기 - “그 숫자, 어떻게 만들었나요?”

## 평가

> 최종 검증 보고서 + 발표. 필수 3요소 - ① 내 데이터는 어떻게 만들어졌는가(시드·판 수·라벨 기준) ② 분포 그림 1장 ③ 불확실성 문장 1개. 셋 중 하나라도 없으면 발표 상한 70%.

## 과제

> 최종 검증 보고서 제출 - 데이터 생성 방법 · 분포 그림 · 불확실성 문장 포함.

⚠️ 이 게임은 교육용으로 크게 단순화한 모형입니다. 여기서 나온 숫자는 이 모형 안에서만 참이며, 실제 현장의 값이나 인과를 그대로 말해 주지 않습니다.

예제를 그대로 실행한 출력은 과제가 아닙니다. 값을 바꿔 보고, 왜 그런지 **3문장(수치·판단·한계)** 으로 적으세요.
