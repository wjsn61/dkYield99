**Python - 함수 def**

함수는 입력(인자)을 받아 일을 하고 결과(반환값)를 돌려줍니다. calculate_yield(plant) 는 한 번 만들면 매
턴 재사용됩니다.

**전공 - 수율 = 전환율 × 선택도 × 분리회수율**

수율은 생산량이 아니라 세 요소의 곱입니다. 하나만 낮아도 전체 수율이 무너집니다 - 이 수업의 핵심 개념입니다.

**실습 - 수율 공식**
