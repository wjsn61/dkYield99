## 이번 주 내용

**Python - csv 읽기 · for 합계 · 함수 채우기**

csv 모듈로 파일을 읽고, for 로 합계를 구하고, 7주에 만든 average() 를 다시 씁니다. 빈 함수 3개를 채우면
끝입니다.

**전공 - 물질수지를 스스로 검산**

공정 데이터는 대개 DCS가 계산해 준 숫자로 옵니다. 산식을 직접 돌려 보는 사람만이 그 숫자를 의심할 수 있습니다.

**실습 - 엑셀 값과 코드 값 대조**

11주에 엑셀로 구한 값과 12주에 코드로 구한 값이 같아야 합니다. 다르면 둘 중 하나가 틀린 것입니다.

**데이터·통계 - 평균 · 표준편차 · 변동계수**

표준편차는 n이 아니라 n-1로 나눕니다(자유도). 변동계수 = 표준편차 ÷ 평균 - 단위가 다른 두 지표 중 무엇이 더
불안정한지 비교할 때 씁니다.
