# 13주 - 분포를 읽는다 - 평균이 숨기는 것

> **학습 목표** - 평균 하나로는 안 보이는 치우침 · 퍼짐 · 튀는 값을 도수분포표와 히스토그램으로 직접 만들어 본다.

## 이 폴더의 예제

| 파일 | 무엇을 | 하는 일 |
|---|---|---|
| `01_histogram.py` | histogram( ) 직접 만들기 ★ | 값을 구간으로 나눠 세는 것이 도수분포표이고, 그것을 막대로 세운 것이 히스토그램입니다. 게임 화면의 그림과 모양이 같은지 맞춰 봅니다. |
| `02_mean_vs_peak.py` | .index( ) - 평균은 봉우리 안에 있나 | 가장 높은 칸(봉우리)과 평균·중앙값의 위치를 견줍니다. 평균만 보고할 때 무엇이 가려지는지 확인합니다. |
| `03_outliers.py` | IQR - 혼자 멀리 있는 값 | 사분위와 IQR 로 '보통 범위' 를 정하고 벗어난 값을 찾습니다. 이상치를 지우는 게 아니라 이유를 찾는 것이 핵심입니다. |

## 이번 주 내용

**Python - 구간을 나눠 세기**

for 안에 if 를 넣어 값이 어느 구간에 드는지 세면 그것이 도수분포표입니다. 히스토그램은 그 표를 막대로 세운 것일
뿐입니다.

**전공 - 평균이 규격을 보장하지 않는다**

평균 순도가 98%여도 퍼짐이 크면 규격 미달 배치가 나옵니다. 현장에서 문제가 되는 것은 늘 평균이 아니라 꼬리 쪽 몇
배치입니다.

**실습 - 내 공정 지표의 분포**

12개월간의 수율·순도를 구간별로 세어 봅니다. 튄 배치가 있다면 그달에 무슨 조건을 바꿨는지 로그에서 찾습니다.

**데이터·통계 - 히스토그램 · 이상치 - 직접 만듭니다**

평균이 같아도 모양은 전혀 다를 수 있습니다. 어디에 몰려 있는가(봉우리), 한쪽으로 쏠렸는가(치우침), 혼자 멀리 있는 값이
있는가(이상치)를 봅니다. 이상치는 지우는 게 아니라 왜 생겼는지 찾는 것입니다.
