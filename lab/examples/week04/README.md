## 이번 주 내용

**Python - 조건문 if / elif / else**

if 조건: 은 조건이 참일 때만 실행합니다. 비교연산자 <, >=, == 로 조건을 만듭니다.

**전공 - 운전 한계·안전 제약**

모든 공정에는 안전·설비·예산의 한계가 있습니다. 가능한 운전과 불가능한 운전을 가르는 규칙이 조건문입니다.

**실습 - 카드 시행 조건**

enact_card() 는 예산이 충분한지, 이미 설치한 일회성 설비인지 if 로 판단해 시행 여부를 정합니다.
