# 3주 - 첫 공정 카드 만들기

> **학습 목표** - 딕셔너리를 직접 편집해 새 카드를 만들고 검사한다.

## 이 폴더의 예제

| 파일 | 무엇을 | 하는 일 |
|---|---|---|
| `01_copy_card.py` | dict( ) 복사 vs 대입(=) | 기존 카드 을(를) 복사해 내 것을 만듭니다. 복사(dict())와 그냥 대입(=)의 차이를 확인하는 것이 핵심입니다. |
| `02_edit_card.py` | .get( ) · .pop( ) - 값 고치기 | 비용과 효과를 내 뜻대로 고칩니다. 딕셔너리 값을 바꾸고 이름표를 더하고 빼는 연습입니다. |
| `03_write_out.py` | isinstance( ) - 붙여넣을 모양으로 찍기 | 내가 만든 카드 을(를) 실제 데이터 파일에 그대로 붙여넣을 수 있는 글자 모양으로 찍어 냅니다. |
| `04_check.py` | not in · or - 검사기 흉내 내기 | 데이터 파일을 터미널에서 직접 실행하면 검사기가 돕니다. 여기서는 검사기가 무엇을 보는지 같은 규칙으로 흉내 내 봅니다. |

**번호 순서대로 여세요.** 앞 파일을 알아야 뒤 파일이 읽힙니다.

각 파일 맨 위에 *이 파일이 하는 일* 이 적혀 있고, 처음 나오는 문법은 그 줄 옆에 주석으로 설명해 두었습니다.

## 이번 주 내용

**Python - 복사·수정·검사**

기존 블록을 복사해 값만 바꾸면 새 카드가 됩니다. 오타·누락은 검사기가 한국어로 알려줍니다.

**전공 - 운전 변수의 선택**

온도·압력·유량·환류비 중 무엇을 건드릴지에 따라 수율·순도·안전·비용이 달라집니다.

**실습 - 검사기로 확인**

카드를 추가한 뒤 python cards_data.py 를 실행하면 validate() 가 오류·경고를 알려줍니다.

## 실습 단계

1. lab/examples/week03/ 를 번호 순서로 열기 - 한 파일에 개념 하나입니다
2. 카드 블록 하나를 통째로 복사
3. 아이디·이름·비용·효과를 새로 바꾸기
4. 검사 실행 → 오류가 나면 메시지대로 고치기
5. 서버 재실행 후 게임에서 새 카드 확인
