## 이번 주 내용

**Python - 복습 체크**

변수·리스트/딕셔너리·조건문·반복문·함수 - 다섯 가지 기초를 모두 사용해 공정팩을 만듭니다.

**전공 - 공정 패키지**

낱개 카드가 아니라 ‘수율 목표를 향한 공정 전략’을 설계합니다. 수율·순도·안전·비용의 균형을 고려합니다.

**실습 - 중간 프로젝트**

카드 5종을 작성·검사한 뒤 게임으로 12개월을 돌려 결과를 발표합니다.

## 실습 단계

1. lab/examples/week08/ 를 번호 순서로 열기 - 한 파일에 개념 하나입니다
2. 1~7주 핵심 개념 복습
3. 카드 5종 설계·검사 통과
