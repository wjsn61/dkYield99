## 이 폴더의 예제

| 파일 | 무엇을 | 하는 일 |
|---|---|---|
| `01_for_basic.py` | for · range( ) · enumerate( ) · .append( ) | 같은 일을 여러 번 반복하는 방법입니다. 목록의 값을 하나씩 꺼내 처리합니다. |
| `02_sum_count.py` | sum( ) · len( ) - 합계와 개수 ★ | for 문으로 값을 더해 가며 합계와 개수를 구합니다. 그 둘을 나누면 나오는 값이 이 과목 후반부의 주인공입니다. |

**번호 순서대로 여세요.** 앞 파일을 알아야 뒤 파일이 읽힙니다.

각 파일 맨 위에 *이 파일이 하는 일* 이 적혀 있고, 처음 나오는 문법은 그 줄 옆에 주석으로 설명해 두었습니다.

## 이번 주 내용

**Python - 반복문 for**

for x in 목록: 은 목록의 값을 하나씩 꺼내 같은 일을 반복합니다. 효과를 하나씩 적용하거나, 설치된 설비를 모두 순회할
때 씁니다.

**전공 - 시계열 운전·누적효과**

설비 유지비·장기효과는 매 턴 누적됩니다. 시간에 따른 변화(동특성)를 이해해야 장기 수율을 예측합니다.

**실습 - 효과 적용과 턴 종료**

apply_effect() 는 효과를 for 로 하나씩 더하고, end_turn() 은 설치된 모든 설비의 유지비·장기효과를
순회합니다.

## 실습 단계

1. lab/examples/week05/ 를 번호 순서로 열기 - 한 파일에 개념 하나입니다
2. apply_effect()와 end_turn() 읽기
3. 효과가 ‘하나씩’ 더해지는 부분 찾기
4. 합계와 개수로 평균 구하기 - for 로 더한 뒤 개수로 나눠 보기
