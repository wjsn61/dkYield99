# 1주 - 오리엔테이션 · 설치 · 공정의 지표를 변수로

> **학습 목표** - 게임을 설치해 한 판 돌려 보고, 화면의 숫자가 코드 속 변수라는 것을 그 자리에서 확인한다.

## 이 폴더의 예제

| 파일 | 무엇을 | 하는 일 |
|---|---|---|
| `01_hello.py` | print( ) - 화면에 글자 찍기 · 사칙연산 | 파이썬에게 처음으로 말을 시켜 봅니다. print() 하나만 씁니다. 따옴표 안의 글자가 그대로 화면에 나오는 것을 확인하는 것이 전부입니다. |
| `02_variables.py` | variable · int · float · str - 값을 담는 상자 | 숫자나 글자에 이름을 붙여 두고 나중에 그 이름으로 꺼내 씁니다. 게임의 예산·수율 같은 지표가 전부 이 '변수' 입니다. |
| `03_game_source.py` | 게임 소스 읽기 - new_plant( ) 의 변수들 | 게임의 공장 상태가 코드 어디에 어떻게 적혀 있는지 봅니다. 실제 소스를 이 파일에 그대로 옮겨 놓았습니다. 전부 '이름 = 값' 일 뿐입니다. |
| `04_change_value.py` | 게임 소스 읽기 - enact_card( ) 의 뺄셈 한 줄 | 가진 돈에서 카드 비용을 빼 봅니다. 게임의 '카드 시행' 이 코드에서는 이 뺄셈 한 줄입니다. |

**번호 순서대로 여세요.** 앞 파일을 알아야 뒤 파일이 읽힙니다.

각 파일 맨 위에 *이 파일이 하는 일* 이 적혀 있고, 처음 나오는 문법은 그 줄 옆에 주석으로 설명해 두었습니다.

## 이번 주 내용

**Python - 설치, 그리고 첫 변수**

Python과 VS Code를 설치합니다. 변수는 값을 담는 상자입니다 - 정수(1000)·실수(92.5)·문자열("공정").
예산 = 1000 처럼 이름에 값을 넣습니다.

**전공 - AI시대 공정 엔지니어링 · 운전의 기초**

실제 플랜트는 조건 하나 바꾸는 데 큰 비용과 위험이 따릅니다. 시뮬레이션은 ‘실패해도 안전하게’ 결과를 미리 실험하는
도구입니다. 그 안의 숫자는 예산·생산량·수율·순도·안전입니다.

**실습 - 12개월 운전 → 그 숫자를 코드에서 찾기**

_start.bat 으로 게임을 켜고 12개월을 운전합니다. 그다음 process_engine.py 의 new_plant() 를
열면, 방금 화면에서 본 지표가 그대로 변수로 적혀 있습니다.

## 실습 단계

1. lab/examples/week01/ 를 번호 순서로 열기 - 한 파일에 개념 하나입니다
2. VS Code 설치 → 확장 ms-python.python 설치 (파이썬은 게임 폴더에 들어 있어 따로 설치하지 않습니다)
3. 파일 → 폴더 열기 로 게임 폴더를 통째로 열고, Ctrl+Shift+P → Python: Select Interpreter 에서 .\python\python.exe 고르기
4. _start.bat 실행 → 게임 한 판 플레이 (12개월)
5. process_engine.py 의 new_plant() 열어 화면에서 본 지표 찾기
6. ‘예산’ 값을 1000 → 1500 으로 바꾸고 새 게임으로 확인
