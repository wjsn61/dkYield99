## 이번 주 내용

**Python - 리스트와 딕셔너리**

리스트 [a, b, c] 는 값을 순서대로, 딕셔너리 {"키": 값} 는 이름표가 붙은 값을 담습니다. 카드 하나는 딕셔너리,
카드 목록은 리스트입니다.

**전공 - 운전 조건과 단위조작**

반응(반응기)·분리(증류탑) 같은 단위조작은 온도·압력·유량·환류비 같은 운전 변수로 조절합니다.

**실습 - 공정 카드 읽기**

cards_data.py 의 카드 20장은 각각 { 아이디·이름·분류·비용·즉시효과·부작용 } 딕셔너리입니다.

## 실습 단계

## 과제

> 운전 카드와 연구(R&D) 카드의 구조 차이(즉시효과 vs 연구기간·성공효과)를 정리하세요.
