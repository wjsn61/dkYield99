## 1️⃣ 데이터를 만든다 (9~10주)

### 게임에서 직접

1. 게임을 하고 **「💾 저장 · 불러오기」** 로 판을 저장합니다.
2. **성공 / 실패 라벨**을 붙입니다. 나중에 두 무리를 비교할 때 씁니다.
3. **「📊 통계 지표 보기 → 📥 엑셀용 CSV」** 를 누르면 `data/` 에 저장됩니다.

### 자동으로 여러 판

```
python run_batch.py --strategy 품질형 --n 20
python run_batch.py --compare 품질형 수율형 --n 20
```

> **왜 여러 번 돌리나요?**
> 한 번 해 보고 "이 카드가 좋다"고 말할 수는 없습니다.
> **같은 카드를 써도 시드가 다르면 결과가 달라집니다.**
> 여러 번 돌려 봐야 '카드 때문'과 '그냥 운'을 구분할 수 있습니다.

돌려 보면 이런 것이 보입니다 — **흔들리는 지표와 안 흔들리는 지표가 있습니다.**
수율과 순도는 매번 다르고, 순도(진값)는 늘 같습니다.
왜 그런지 생각해 보는 것이 9주 과제입니다.

## 2️⃣ 엑셀로 읽는다 (11주)

`data/` 의 CSV를 엑셀로 엽니다. (한글이 깨지지 않게 저장해 두었습니다)

| 하는 일 | 엑셀 함수 |
|---|---|
| 평균 | `=AVERAGE(범위)` |
| 중앙값 | `=MEDIAN(범위)` |
| **표준편차** | `=STDEV.S(범위)` ← **S** 는 표본(Sample) |
| 최소·최대 | `=MIN(범위)` `=MAX(범위)` |
| 라벨별 집계 | 피벗테이블 |

⚠️ `=STDEV.P()` 도 있습니다. 이건 n으로 나눕니다. **이 수업에서는 `STDEV.S` 를 씁니다.**

## 3️⃣ 코드로 직접 만든다 (12주) — 이 수업의 핵심

```
python w12_basic.py
```

처음 실행하면 이렇게 나옵니다.

```
  [X] 평균 my_mean()
        아직 만들지 않았습니다. (pass 를 지우고 return 을 쓰세요)
```

`w12_basic.py` 를 열고 ✏️ 표시가 있는 세 함수를 채우세요.

- `my_mean()` — 합계 ÷ 개수
- `my_stdev()` — 편차를 제곱해서 더하고, **n−1**로 나누고, 제곱근
- `my_cv()` — 표준편차 ÷ 평균 × 100

다 채우면 채점기가 확인해 줍니다. 틀리면 이렇게 알려 줍니다.

```
  [X] 표준편차 my_stdev()
        2.8284 가 나왔습니다. 아주 가깝습니다!
        n(5) 이 아니라 n-1(4) 로 나누어야 합니다. (자유도)
        정답은 3.1623 입니다. 엑셀의 =STDEV.S() 와 같은 값입니다.
```

### ★ 그리고 세 값을 맞춰 봅니다

| 어디서 | 값 |
|---|---|
| ① 내가 짠 코드 | `python w12_basic.py` |
| ② 엑셀 | `=STDEV.S(범위)` |
| ③ AI | "이 숫자들의 표준편차를 구해 줘" |

**셋이 맞아떨어질 때** 비로소 그 숫자를 믿을 수 있습니다.
다르면 어느 쪽이 틀렸는지 찾는 것이 과제입니다.

> AI는 모르는 것을 모른다고 말하지 않습니다.
> 그럴듯한 숫자를 자신 있게 내놓습니다.
> **검산할 수 있는 사람만** 그 답을 쓸 수 있습니다.

## 5️⃣ 분포와 비교 (13~14주)

상관계수·회귀선은 **이 과목에서 다루지 않습니다.**
그 시간을 **분포를 읽는 일**과 **두 무리를 견주는 일**에 씁니다.
평생 쓰게 될 통계는 대부분 이 둘입니다.

**13주 — 분포를 읽는다.** 평균 하나로는 안 보이는 것을 봅니다.

```python
구간 = {}
for v in 값들:
    칸 = int(v // 5) * 5        # 5 단위로 묶기
    구간[칸] = 구간.get(칸, 0) + 1

for 칸 in sorted(구간):
    print(칸, "■" * 구간[칸], 구간[칸])
```

이게 **도수분포표**이고, 막대로 세우면 **히스토그램**입니다.
게임의 「📊 통계 지표 보기」 히스토그램과 모양이 같아야 합니다.

**14주 — 두 무리를 견준다.** 새로 배울 문법이 없습니다.

```python
차이 = my_mean(성공) - my_mean(실패)
퍼짐 = (my_stdev(성공) + my_stdev(실패)) / 2
print(차이 / 퍼짐)              # 1보다 크면 눈에 띄는 차이
```

평균이 5 차이 나도 각 무리가 ±10씩 흔들리면 **그 차이는 우연일 수 있습니다.**
그래서 평균 차이만 보지 않고 **퍼짐과 견줍니다.** 이 한 줄이 통계적 판단의 뼈대입니다.

그리고 반드시 한 번 더 묻습니다 — **그 차이가 정말 내가 한 것 때문일까?**

- `환류비`가 높은 판일수록 `순도`도 높아 보입니다. 원인일까요?
  (아닙니다 — 같은 카드가 둘 다 올렸을 뿐, 환류비만 바꿔서는 순도가 안 변합니다)
- 누적이익은 달이 갈수록 늘 커집니다. 그렇다고 시간이 이익의 원인은 아닙니다.
- 성공/실패를 5개 지표로 비교하면 **지표마다 결론이 갈립니다.**
  유리한 것만 골라 보고하면 안 됩니다.

## ❓ 자주 하는 실수

| 이런 일이 생기면 | 이렇게 하세요 |
|---|---|
| `data 폴더에 CSV가 없습니다` | 게임에서 「📊 통계 지표 보기 → 📥 엑셀용 CSV」를 먼저 누르세요 |

| 그림의 한글이 네모로 나옴 | `setup_matplotlib()` 이 폰트를 못 찾은 경우입니다. 조교에게 알려 주세요 |
| 전략을 돌렸는데 카드가 안 들어감 | 예산이 부족하거나 이미 설치된 설비입니다. `python strategies.py` 로 확인하세요 |
