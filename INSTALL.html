1폴더 준비

dkYield99 폴더 전체를 원하는 위치(예: C:\dk\dkYield99)에 통째로 복사합니다.

⚠️ 안에 있는 python\ 폴더를 지우지 마세요. 게임용 파이썬이 들어 있습니다.
dkYield99\ ├─ _start.bat ← 실행 (더블클릭) ├─ install.bat ← (선택) 설치 상태 점검 ├─ stop.bat ← 서버 끄기 ├─ python\ ← 게임용 파이썬 (지우지 마세요) ├─ server\ web\ ← 게임 본체

2실행 — 딱 한 번의 더블클릭

_start.bat → 브라우저에서 http://127.0.0.1:5000 자동 열림 → 공정 가동하기 ⚗️
이미 서버가 켜져 있으면 새로 띄우지 않고 브라우저만 엽니다(중복 실행 안전).
급하면 install.bat 없이 _start.bat 하나만 눌러도 됩니다.

끄기: 검은 서버 창에서 Ctrl + C, 또는 stop.bat 더블클릭.
